# Static Shock

a static site generator written in ~~swift~~ c

## usage

`$ staticshock folder`

### project structure

```
.
| index.md
| any html or markdown files
| post.html template
| header.html template
| footer.html template
|
|__ posts
|   | markdown files
|
|__ css
|   | css files
|
|__ js
    | js files     
```
